# ROS2 Zero to Autonomy

プログラミング・ロボット開発初心者が、
Python / C++ / Linux / ROS 2を学習し、
最終的に自律移動ロボットを開発するプロジェクトです。

## Goal

Gazebo上で以下の機能を持つ自律移動ロボットを開発します。

- 地図作成
- 自己位置推定
- 障害物回避
- 自律移動
- 複数地点の自動巡回
- 異常検知
