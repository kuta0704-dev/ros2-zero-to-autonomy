# STEP1 - Linux / WSL2 基礎

## 実施内容

- WindowsにWSL2とUbuntu 24.04を導入
- Ubuntuのユーザー環境を設定
- Linuxの基本的なファイル・ディレクトリ操作を実施
- Linux側の `/home` とWindows側の `/mnt/c` を確認
- `sudo` と `root` による管理者権限を確認
- `apt` を使ってパッケージ情報を更新
- `tree` をインストール
- UbuntuからWindowsのCドライブへアクセス
- Linux側にROS 2開発用ディレクトリを作成
- GitHubリポジトリをUbuntu側へclone
- Ubuntu側のGitユーザー情報を設定
- Gitリポジトリの状態を確認

## 使用した主なコマンド

`whoami` `pwd` `ls` `cd` `mkdir` `touch` `echo` `cat` `cp` `mv` `rm` `sudo` `apt` `tree` `git`
